# Online_retail_sales-powerbi-analysis-
This project is an end-to-end Power BI project analyzing 500,000+ online retail transactions. Cleaned and transformed data using Power Query, built DAX measures, and created an interactive dashboard covering revenue, orders, customers, products, returns, and geography to support data-driven decisions.  
The dashboard was designed to generate actionable business insights and support decisions around sales performance, inventory planning, customer retention, product performance, and return analysis.
Tools: Power BI | Power Query | DAX | Data Visualization.
